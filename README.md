# Food Waste Predictor 🍽️

A beginner-friendly Machine Learning project that predicts the expected level of food waste as **Low, Medium, or High**.

## 🎯 Objective

The project predicts food waste based on:

- Number of people
- Food prepared (kg)
- Meal type
- Day type
- Previous food waste (kg)

## 🤖 Machine Learning Algorithm

**Decision Tree Classifier**

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
